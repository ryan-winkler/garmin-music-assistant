# Garmin Controller Wire Protocol (`v1`)

* **Namespace:** `/api/garmin/v1/`
* **API Version:** `1` (additive-only within `v1`; breaking changes require `/api/garmin/v2/`)
* **Content-Type:** `application/json; charset=utf-8` on every response (including lists and errors)
* **Root Shape Invariant:** Every response is a JSON object (`{...}`). Never `null`, empty body, HTTP `204`, or bare JSON array (`[...]`).

## Authentication & Headers

Every endpoint (including `/health`) requires a valid Music Assistant Bearer token:

```http
Authorization: Bearer <music-assistant-long-lived-token>
X-Garmin-Req-Id: <client-request-sequence>
X-Garmin-App-Version: <watch-app-semver>
```

Tokens must never be passed in query parameters or written to server/watch logs.

## Hard UTF-8 Byte Budgets

| Endpoint | Method | Scope | Max UTF-8 Bytes |
| :--- | :--- | :--- | :--- |
| `/api/garmin/v1/health` | `GET` | `players.read` | `512 B` |
| `/api/garmin/v1/players` | `GET` | `players.read` | `3072 B` |
| `/api/garmin/v1/state` | `GET` | `players.read` | `1024 B` |
| `/api/garmin/v1/action` | `POST` | Action-dependent | `1024 B` |
| `/api/garmin/v1/items` | `GET` | `queues.read` or `library.read` | `3072 B` |
| Any Error (`4xx` / `5xx`) | Any | — | `384 B` |

## Text Sanitization

All watch-rendered text fields strip 4-byte UTF-8 glyphs (emoji/supplementary planes) and control characters, collapse repeated whitespace, and truncate on Unicode code-point boundaries using ASCII `"..."`.

## Endpoints

### 1. `GET /api/garmin/v1/health`
Returns server handshake metadata.

```json
{"ok": true, "api_version": 1, "plugin_version": "0.1.0", "ma_version": "2.11.0"}
```

### 2. `GET /api/garmin/v1/players?offset=0&limit=15`
Returns available enabled players sorted deterministically: `playing` > `paused` > `idle`, prioritizing phone/mobile background players (`sendspin` / `builtin_player`, `ph: true`) within each state tier, then alphabetical by name.

```json
{
  "ok": true,
  "total": 2,
  "offset": 0,
  "limit": 15,
  "items": [
    {"id": "sendspin_phone", "n": "Ryan Phone", "s": "playing", "v": 65, "m": false, "g": false, "q": true, "ph": true}
  ]
}
```

### 3. `GET /api/garmin/v1/state?player_id=<id>`
If `player_id` is omitted, selects the first currently playing available player (or first paused, or first available).

```json
{
  "ok": true,
  "p": {
    "id": "living_room",
    "n": "Living Room",
    "s": "playing",
    "v": 45,
    "m": false,
    "t": "Track Title",
    "a": "Artist Name",
    "al": "Album Name",
    "el": 42,
    "du": 215,
    "rp": "all",
    "sh": false,
    "fav": true,
    "nt": "Next Track",
    "caps": {
      "vol": true,
      "mute": true,
      "seek": true,
      "q": true,
      "rp": true,
      "sh": true,
      "fav": true,
      "grp": false
    }
  }
}
```

### 4. `POST /api/garmin/v1/action`
Executes a listening action, waits up to `settle_timeout_ms` (default 500 ms) for matching `PLAYER_UPDATED` / `QUEUE_UPDATED`, and returns fresh state.

Request:
```json
{"player_id": "living_room", "action": "play_pause", "value": null}
```

Supported `action` values and required scopes:
* `play`, `pause`, `play_pause`, `stop`, `next`, `previous` (`players.control`)
* `volume_set` (`0..100`), `volume_up`, `volume_down`, `mute` (`bool` or `"toggle"`) (`players.control`; routes to group volume commands when `caps.grp` is true)
* `seek` (`{"delta": int}` or `{"position": int}` or integer delta seconds) (`players.control`)
* `repeat` (`"off"` | `"all"` | `"one"` | `"cycle"`) (`queues.control` if queue active, else `players.control`)
* `shuffle` (`bool` or `"toggle"`) (`queues.control` if queue active, else `players.control`)
* `favorite` (`null`) (`library.write`)
* `play_index` (integer queue index) (`queues.control`)
* `play_media` (media URI string) (`queues.control`)

Response:
```json
{"ok": true, "settled": true, "p": { "...PlayerSnapshot..." }}
```

### 5. `GET /api/garmin/v1/items?kind=queue|playlists|favorites&player_id=<id>&offset=0&limit=10`
Unified paginated listing for Queue (`kind=queue`, requires `player_id` and `queues.read`), Playlists (`kind=playlists`, requires `library.read`), and Favorites (`kind=favorites`, requires `library.read`). Hard cap `limit <= 12`.

```json
{
  "ok": true,
  "kind": "queue",
  "total": 25,
  "offset": 0,
  "limit": 10,
  "cur": 2,
  "items": [
    {"k": "2", "t": "Current Track", "sub": "Artist", "c": true}
  ]
}
```

### Error Envelope (`4xx` / `5xx`)

```json
{"ok": false, "code": "auth_required", "error": "Authentication required", "req_id": "42"}
```
